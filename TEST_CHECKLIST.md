# ION BAU V1 – Testcheckliste

## Admin / Geschäftsführung
- Login: admin@ionbau.local / admin
- Unternehmen einrichten: Name + Logo + Anschrift + Kontakt
- Mitarbeiter anlegen, bearbeiten, aktiv/inaktiv, Rolle ändern
- Projekt anlegen, bearbeiten, Kontakte und Adresse prüfen
- Projektmitgliedschaften ändern
- Aufgabe mit mehreren Zuständigen anlegen
- Projektchat: Nachricht, @Erwähnung, Pin, Datei, Sprachnachricht (Browserfreigabe nötig)
- Nachricht in Aufgabe / Materialanforderung umwandeln
- Stunden erfassen, Monatssoll ändern, Monatsabschluss ausführen
- Urlaub genehmigen/ablehnen, Krank/Frei erfassen
- Mitarbeiterplanung: mehrere Projekte am selben Tag erfassen
- Baustellenplanung: Phase + Personalbedarf anlegen
- Material: Status Angefordert → Bestellt → Unterwegs → Geliefert
- Dokumente ausschließlich im Projekt; Ordner 01–10; Sichtbarkeit für Mitarbeiter
- Suche nach Projekt/Aufgabe/Dokument
- Backup exportieren/importieren

## Mitarbeiter
- Login: ivan@ionbau.local / ivan
- Nur eigene/relevante Projekte sehen
- Eigene Aufgaben bearbeiten (Status/Kommentar/Anhang)
- Projektchat verwenden
- Stunden als reine Stundenanzahl erfassen
- Eigene Planung sehen
- Material anfordern und Status sehen
- Urlaub beantragen / krank melden
- Nur freigegebene Dokumentordner sehen
